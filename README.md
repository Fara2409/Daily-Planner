# Daily Planner

Напоминания и календарь дел с голосовым вводом (PWA).

## Запуск на компьютере
```
npm install
npm run dev
```
Затем откройте адрес, который покажет консоль (обычно http://localhost:5173/Daily-Planner/).

## Публикация
Каждая отправка в ветку `main` автоматически публикует сайт на GitHub Pages
(см. `.github/workflows/deploy.yml`).
